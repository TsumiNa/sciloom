Example walkthroughs

Every walkthrough includes the actual runnable source and its expected result. Generated companions are included where the target can produce them; gated examples show the current diagnostic instead. Use a source checkout to run the listed commands. Downloads are learning references; generated JSON records source paths relative to the repository root.

For experiment authors

Example What it teaches
Function calls Pass a value to a child Function and receive its result
Agitation Save a speed, start or stop a shaker, and compile for AutoSuite
Scale values Copy a list and multiply each element by a factor
Non Zero Array Min Find the smallest value above a threshold in supplied numbers
Stir a rack of samples Choose a speed from supplied volumes and count start requests
Prepare labels Trim supplied text, select a part and return independent labels
Quantity conversion Calculate volumes and time differences with explicit units
Numeric operations Calculate whole portions and an absolute volume difference
Record values Log supplied sample labels and typed volumes
Confirm samples Require OK before recording a ready sample
Timestamp a filename Capture local wall time once and build a filename
Timed agitation Wait relative to a timer before explicitly stopping agitation
Read a reagent table Select a heading and aligned typed columns; AutoSuite compilation remains gated
Append a sample log Append one text record; AutoSuite mode and encoding still need verification
Resolve sample locations Combine named Zones and count distinct wells
Visit sample locations Visit one well at a time using a declared Zone loop variable
Label selected wells Write a sample identifier to selected wells and read it back
Run a selected shaker Configure, select, start, wait and stop; native emission remains gated
Label wells and append a log Combine confirmation, time, ordered metadata changes and file writes
Calculate a volume chunk Calculate capacity, partial fills and a caller-supplied resume point

For contributors

Example What it verifies
Agitation IR JSON persistence and configured/applied state snapshots
List IR Direct construction and value semantics
Reference environment Shared event history and independent session state
Typed log IR Capture a quantity in an immutable event after JSON restoration
Confirmation IR Consume an explicit response after JSON restoration
Wall-time IR Supply an aware clock and inspect an immutable read event
Elapsed-time IR Advance a virtual clock without sleeping or changing wall time
Typed CSV IR Restore a read from JSON and execute with explicit file bytes
CSV append IR Append twice in memory and inspect captured records
Zone IR Query an explicit immutable location directory after JSON restoration
Zone traversal IR Index an ordered selection and visit complete groups after JSON restoration
Physical device snapshots Select two controllers while retaining independent applied values and running states
Well property IR Supply an explicit metadata store and inspect immutable read/write events
Independent device A new property, command and target outside core
Portable agitation Device specialization and rebinding the same authored JSON
Complete workflows from IR Three independent builders, JSON restoration and explicit reference services
Volume chunk after JSON Source-derived quantity arithmetic and repeated calls after restoration
