Reference interpreter

Reference execution specifies session state, value copying and limitations. This interpreter does not run physical equipment.

sciloom.core.interpreter.Interpreter 

Interpreter(
    program: Program,
    *,
    config: ExecutionConfig | None = None,
)

A session owns persistent internal state; each run gets fresh call frames.

On failure, earlier state writes remain visible to subsequent runs. This is sequential execution, not a transactional rollback or physical simulator.

Create an independent reference session and initialize internal defaults.

Parameters:

Name Type Description Default
program Program

Valid semantic program with device conditions already specialized.

 required
config ExecutionConfig | None

Optional execution budgets.

 None

Raises:

Type Description
IRValidationError

The semantic model is invalid.
ExecutionError

Unselected device conditions remain.

run(
    *, inputs: Mapping[str, InputValue] | None = None
) -> ExecutionResult

Execute the selected entry with fresh call frames and persistent session state.

Parameters:

Name Type Description Default
inputs Mapping[str, InputValue] | None

Exactly the entry's named inputs; omit for a parameterless entry.

 None

Returns:

Type Description
ExecutionResult

An independent snapshot of outputs, internal state and device events.

Raises:

Type Description
ExecutionError

Inputs, operations or indices are invalid, state is uninitialized, an extension lacks semantics, or a budget is exhausted.

Earlier state writes survive a failure. This is not hardware simulation.
