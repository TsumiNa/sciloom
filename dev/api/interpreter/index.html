Reference interpreter

Reference execution specifies session state, value copying and limitations. This interpreter does not run physical equipment.

A session owns persistent internal state; each run gets fresh call frames.

On failure, earlier state writes remain visible to subsequent runs. This is sequential execution, not a transactional rollback or physical simulator.

Create an independent reference session and initialize internal defaults.

sciloom.core.interpreter.ReferenceEnvironment dataclass 

ReferenceEnvironment(
    *,
    acknowledgements: QueuedAcknowledgements | None = None,
    wall_clock: WallClock | None = None,
)

Caller-owned external context and chronological event history.

An omitted environment creates an independent context for each Interpreter. Pass the same instance explicitly to share its history across sessions. Function variables and device configurations remain session-owned.

Services are added with the capabilities that use them. This environment never reads host files, samples a real clock or acknowledges messages by default. Runs are sequential; no concurrent or transactional behavior is implied. Completed events remain visible after later execution failures.

acknowledgements class-attribute instance-attribute 

acknowledgements: QueuedAcknowledgements | None

Explicit OK responses; absent by default and shared only when supplied.

wall_clock class-attribute instance-attribute 

wall_clock: WallClock | None

Explicit aware wall-time provider; never defaults to the host clock.

events property 

events: tuple[ExecutionEvent, ...]

Return an immutable history snapshot across runs using this environment.
