sciloom_autosuite.AutoSuiteIndividualShaker dataclass 

AutoSuiteIndividualShaker(*, zone: str, device_id: str)

Bases: Agitator

Bind one logical controller to a fixed zone on one individual shaker.

device_id identifies the shaker, not the vessel/rack listed in the zone. The caller supplies a matching existing application configuration. This record does not discover hardware or establish physical speed limits.

sciloom_autosuite.write_autosuite_review 

write_autosuite_review(
    result: CompileResult,
    *,
    target: AutoSuiteTarget,
    path: str | Path,
) -> AutoSuiteDeploymentReport

Write an ASFP and same-base deployment report after checking their association.

Parameters:

Name Type Description Default
result CompileResult

Successful result from the standard compilation pipeline.

 required
target AutoSuiteTarget

AutoSuite target whose profiles and settings should be assessed.

 required
path str | Path

Artifact filename; the sidecar replaces its suffix with .deployment.json.

 required

Returns:

Type Description
AutoSuiteDeploymentReport

The report written to the sidecar, including artifact and selected IR hashes.

Raises:

Type Description
ValueError

Identity, concrete binding, artifact or selected-result checks fail, or the two destination paths coincide.
IRValidationError

Selected semantic IR is malformed.
CompilationError

Existing binding, state or target validation rejects the result.
OSError

Either destination cannot be written. Two-file writes are not atomic.

This does not resolve or specialize authored IR, compile a second program, mutate a target cache or run Executor. All semantic checks precede writes.
