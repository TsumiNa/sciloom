Runtime CSV

Import csv from sciloom. See reading rules. SciLoom checks result element types; Python typing checks Column metadata and call arguments but cannot infer arbitrary result tuples here.

sciloom.csv

Typed runtime CSV reads with explicit columns and complete result tuples.
