sciloom.core.compiler.compile_ir 

compile_ir(
    program: Program, *, target: Target
) -> CompileResult

Validate, specialize and compile a program without parsing Python source.

Parameters:

Name Type Description Default
program Program

Authored semantic IR from any frontend or JSON.

 required
target Target

Explicit target implementing binding resolution, validation and emission.

 required

Returns:

Type Description
CompileResult

Both semantic programs and the emitted artifact.

Raises:

Type Description
TypeError

The target is missing a required member, or the returned bindings are not DeviceBindings. Argument and return types are a static contract, checked by a type checker rather than here.
IRValidationError

The authored or specialized IR is invalid.
CompilationError

Binding, configuration or target validation fails.

Neither XML assumptions nor backend-private state belong in this pipeline.

sciloom.core.specialization.specialize 

specialize(
    program: Program, *, bindings: DeviceBindings
) -> Program

Validate, select device branches and retain reachable high-level functions.

Node identities and source spans survive selection. Resources receive trusted concrete interface types; deployment addresses and private backend state never enter this program. Missing bindings are errors even for a false device query.

Parameters:

Name Type Description Default
program Program

Authored program; not modified by this function.

 required
bindings DeviceBindings

Trusted deployment facts supplied by the selected target.

 required

Returns:

Type Description
Program

A new program with selected branches and reachable functions.

Raises:

Type Description
IRValidationError

Input or resulting semantics are invalid.
CompilationError

Bindings are missing, incompatible or untrusted.
