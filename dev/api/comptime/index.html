Compile-time device queries

Import comptime from sciloom. These predicates belong only in compiled if/elif conditions; host calls raise TypeError.

sciloom.comptime.can_write 

can_write(device: BaseDevice, name: str) -> bool

Query the bound device's explicit writable capability.

Parameters:

Name Type Description Default
device BaseDevice

Logical device slot inside a runtime method.

 required
name str

String literal naming a declared property.

 required

Returns:

Type Description
bool

A compile-time Boolean used only in an if/elif condition.

Raises:

Type Description
TypeError

Called directly by host Python.

This query does not narrow the Python device type.

is_device(
    device: BaseDevice, device_type: type[T]
) -> TypeGuard[T]

Narrow a logical interface to a bound device type or subtype.

Parameters:

Name Type Description Default
device BaseDevice

Logical device slot inside a runtime method.

 required
device_type type[T]

Declared device class with a versioned semantic identity.

 required

Returns:

Type Description

A type guard recognized by type checkers and compiled if/elif conditions.

Raises:

Type Description
TypeError

Called directly by host Python.
