# API reference

Signatures, types, bases and descriptions on these pages come from the checked-out
Python source. Search is scoped to the documentation version you are reading;
searching a symbol such as `ConfigureProperty` links directly to its definition.

The [user guide](../user-guide/index.md) explains how to write experiments.

fit together. Private helpers, tests and internal XML generation are not part of
this catalogue.

immutable reference directory.
