# Developer Guide overview

This guide is for contributors: people who add a device family or a profile,
write an equipment target, or work on SciLoom itself. It assumes the
[User Guide](../user-guide/index.md) and uses the semantic IR where an author
never needs to.

**[Tutorial](tutorial/index.md).** Eight pages build a heater family, two
profiles, a target, the rejections a contributor writes, an adaptive program and
a reference execution, one step per page, verified on every change.

**Reference.** [Architecture and ownership](reference/architecture.md), the
[compilation pipeline](reference/pipeline.md), the
[Target contract](reference/target-contract.md),
[device contracts](reference/device-contracts.md), the
[semantic IR and JSON v4](reference/ir.md),
[reference execution](reference/interpreter.md) and
[verification](reference/verification.md).

**Project.** [Typing and tests](typing-and-tests.md),
[building documentation](documentation.md),
[versioned publication](publication.md) and [brand assets](brand.md).

The [glossary](../introduction/glossary.md) defines the terms used across the
site, and the [API reference](../api/index.md) documents the contributor
interfaces extracted from the source.
