# Stir-rack example

## Goal

Add the User Guide tutorial's running program as a real, committed, runnable
example, so the series has a complete program to equal and readers have a
download.

## Scope

`examples/stir_rack.py` with the classes the tutorial introduces, in order:

- `CountStirs(Function)`: `stirs: Var[int] = 0`, incremented on every call.
- `ChooseSpeed(Function)`: `volume: Input[float]`, `speed: Output[RotationalSpeed]`;
  `300 * rpm` below two millilitres, `600 * rpm` otherwise.
- `LargestVolume(Function)`: `volumes: Input[list[float]]`, `largest: Output[float]`,
  `index: Var[int] = 0`; a `while` loop with `len` and indexing, both outputs
  reset at the top of the call.
- `StirRack(Function)`: `volumes: Input[list[float]]`, `enabled: Input[bool]`,
  `shaker: Agitator`, `largest: Var[float] = 0.0`, `speed: Var[RotationalSpeed] = 0 * rpm`;
  `__init__` creates the three children; the runtime method measures, chooses,
  then either configures the shaker and starts it and counts, or stops it.
- `__main__`: `AutoSuiteTarget(devices={"shaker": AutoSuiteIndividualShaker(zone="Heater Shaker 23", device_id="23")})`,
  compile, write beside the source, print `stir_rack.asfp`.

Module docstring per the example-output rules: audience, run command, expected
terminal output, what the program does. Companion `examples/stir_rack.asfp`
generated by running. Walkthrough `website/docs/examples/stir-rack.md` in the
existing template, pointing at the tutorial rather than re-explaining. Register
it: `website/docs/examples/index.md` row, `website/mkdocs.yml` Examples nav,
`website/tools/site.py` `EXAMPLES` (`stir_rack.py`, `stir_rack.asfp`),
`website/tools/handbook_test.py` walkthrough row, `.github/workflows/ci.yml`
run line, `pyproject.toml` mypy `files`, README runnable-example list.

`examples/agitation.py` is untouched; it stays the focused start/stop example.
